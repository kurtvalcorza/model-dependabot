# MDB502: The pinned base model is no longer publicly available

Alert kind `base_model_unavailable`, family base model.

Related watch kinds: `base_model_refused`, `base_model_unrecognised`

## What raises it

The pinned base model is no longer publicly available: the hub answers that it does not exist. Severity LOW by policy.

## What it does not prove

Without an account a deletion and a move to private look alike, so it does not say which. A refused request is a `base_model_refused` watch event, and an answer this tool cannot read is `base_model_unrecognised`.

## How it closes

It is cleared when the base model is public again, and fixed when a new version no longer pins it.

## How to fix or accept it

Find where the base model now lives and pin it, or dismiss the alert with a reason. A dismissal holds: a later check that finds the same cause with no new evidence opens no new alert and lists the dismissed alert under the model's `dismissals_held`. New evidence (a changed record, another matched identifier, a higher severity) opens a new alert whose cause names the dismissed one under `reopens`.
