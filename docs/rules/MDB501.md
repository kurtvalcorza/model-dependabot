# MDB501: The pinned base model is disabled

Alert kind `base_model_disabled`, family base model.

Related watch kinds: `base_model_new_revision`, `base_model_new_version_pointer`, `gating_changed`, `card_changed`, `base_model_moved`

## What raises it

The hub reports the pinned base model repository as disabled. Severity MODERATE by policy.

## What it does not prove

It does not say why. Other changes to the base model are watch events: a new revision (`base_model_new_revision`), a new version pointer (`base_model_new_version_pointer`), changed gating (`gating_changed`), a changed card (`card_changed`) or a move (`base_model_moved`).

## How it closes

It is cleared when the repository is no longer disabled, and fixed when a new version no longer pins the base model.

## How to fix or accept it

Move to another base model and register the new inventory, or dismiss it with a reason. A dismissal holds: a later check that finds the same cause with no new evidence opens no new alert and lists the dismissed alert under the model's `dismissals_held`. New evidence (a changed record, another matched identifier, a higher severity) opens a new alert whose cause names the dismissed one under `reopens`.
