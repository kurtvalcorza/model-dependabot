# MDB103: A code-capable weight file under the strict format policy

Alert kind `format_policy`, family weight files.

Related watch kinds: `pickle_format`, `format_claim_contradicted`, `format_claim_unreadable`

## What raises it

The model's format policy is `strict` (`policy ID --format strict --by NAME`) and the current version pins a weight file in a format that can run code when loaded, with no pinned code-free file beside it. Severity MODERATE by policy; the evidence is the owner's recorded policy.

## What it does not prove

It says nothing about what the file contains: it is a rule about formats. Under the default policy the same file is only a `pickle_format` watch event.

## How it closes

It is cleared when the policy returns to `default` or a code-free file is pinned beside it, and fixed when a new version no longer pins the file.

## How to fix or accept it

Export the weights to a code-free format and register the new version, or set the policy back to `default`. A dismissal holds: a later check that finds the same cause with no new evidence opens no new alert and lists the dismissed alert under the model's `dismissals_held`. New evidence (a changed record, another matched identifier, a higher severity) opens a new alert whose cause names the dismissed one under `reopens`.
